# AI-LOG: Какой ИИ, для чего, что принял/отклонил

## Инструкция для кандидата

Есть два способа сдать лог использования ИИ — выбери любой:

- **(A) Заполнить этот файл** своими словами (шаблон ниже).
- **(B) Приложить сырой лог сессии** из своего инструмента (Claude Code / ChatGPT-share / Cursor history и т.п.) — положи файл в репозиторий или вставь ссылку сюда. В этом случае добавь сверху 2–3 строки: где ИИ был решающим и что ты отклонил/переделал.

Если ИИ не использовал — просто напиши это здесь.

---

Если выбрал вариант (A), по каждому обращению к ИИ:

- **ИИ:** какой инструмент использовал (ChatGPT, Claude, GitHub Copilot и т.д.)
- **Для чего:** конкретная задача
- **Принял / Отклонил / Доработал:** что взял из предложения, что переделал и почему

Пиши свободным списком — формат ниже лишь показывает уровень детализации, не структуру твоего решения.
